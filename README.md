# From Edin to Whiyet

An ASP.NET Core static web project with an animated envelope and letter page.

## Open in Visual Studio

1. Open Visual Studio.
2. Choose **File > Open > Project/Solution**.
3. Select `FromEdinToWhiyet.sln`.
4. Press the green Play button to run the project.

The page is served from `wwwroot/index.html`.
